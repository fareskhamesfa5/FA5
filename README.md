# FA5 — فارس الجيل الخامس

موقع تعريفي عربي باتجاه RTL، مبني باستخدام HTML وCSS وJavaScript عادي، ومناسب للنشر على GitHub Pages.

## هيكل المشروع

```
FA5/
├── index.html
├── README.md
├── assets/
│   ├── fA5-logo.png
│   └── fares-profile.jpg
├── css/
│   └── styles.css
└── js/
    └── main.js
```

## التشغيل والنشر

- افتح `index.html` مباشرة لمعاينة الموقع.
- يعتمد الخط على Google Fonts، والأيقونات على Font Awesome CDN.
- الصور الموجودة في `assets/` محلية داخل المستودع.
- نموذج التواصل يجهز رسالة عبر تطبيق البريد الافتراضي؛ لا يدّعي إرسال الرسالة أو تخزين بياناتها على الخادم.
- للنشر عبر GitHub Pages: من Settings → Pages اختر فرع `main` والمجلد `/(root)`.

## أقسام الموقع

الرئيسية، من نحن، الخدمات، مجالات العمل، والتواصل.
