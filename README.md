# FA5 — فارس الجيل الخامس

موقع تعريفي عربي باتجاه RTL، يعرض الهوية والخدمات ومجالات العمل ومواقع المشروع، مع تصميم متجاوب للموبايل والتابلت والكمبيوتر.

## هيكل الملفات

```
FA5/
├── index.html
├── manifest.json
├── sw.js
├── README.md
├── assets/
│   ├── fA5-logo.svg
│   ├── My fares.jpeg
│   └── pwa-icon.svg
├── css/
│   └── styles.css
└── js/
    └── main.js
```

## المميزات

- واجهة عربية كاملة باتجاه RTL.
- تصميم متجاوب مع الشاشات المختلفة.
- مظهر داكن وفاتح مع حفظ اختيار الزائر محليًا.
- قائمة تنقل للموبايل مع حالة وصول واضحة.
- تصفية مجالات العمل حسب النوع.
- أسئلة شائعة تفاعلية.
- قسم لمواقع المشروع مع نافذة عدّ تنازلي لموعد الإطلاق.
- إمكانية تثبيت الموقع كتطبيق عند دعم المتصفح لذلك.
- Service Worker لتخزين ملفات الواجهة الأساسية ودعم الاستخدام دون اتصال.
- نموذج تواصل يجهّز رسالة عبر تطبيق البريد الافتراضي؛ لا يخزّن بيانات الزائر ولا يرسلها إلى خادم.
- مراعاة إعداد تقليل الحركة في الجهاز.

## التشغيل والنشر

يمكن فتح `index.html` مباشرة للمعاينة. ولتفعيل التثبيت وميزات Service Worker، انشر الموقع عبر HTTPS، مثل GitHub Pages.

في GitHub Pages اختر الفرع `main` والمجلد الجذر `/(root)`.

## ملاحظات

- أي نماذج معروضة في قسم مجالات العمل هي تصورات توضيحية وليست ادعاءً بمشروعات منفذة أو عملاء حقيقيين.
- أيقونة التطبيق في `manifest.json` تستخدم شعار FA5 نفسه الظاهر في الموقع.
- نموذج التواصل يفتح تطبيق البريد لدى الزائر، ويحتاج الزائر إلى تأكيد الإرسال بنفسه.


## الإعلانات (Google AdSense)

- تمت إضافة مُحمّل Auto Ads، لكنه يظل متوقفًا افتراضيًا حتى إدخال معرّف ناشر AdSense معتمد.
- بعد موافقة Google على الموقع، افتح js/ads-config.js وضع معرّف الناشر بصيغة ca-pub-XXXXXXXXXXXXXXXX، ثم فعّل Auto ads من لوحة AdSense.
- راجع privacy.html وأكمل أي إفصاحات أو إعدادات موافقة مطلوبة حسب جمهور الموقع والقوانين المنطبقة.
- لا تضع معرّفًا تجريبيًا أو معرّف حساب شخص آخر. لا تنقر على إعلانات موقعك ولا تطلب من الزوار النقر عليها.
- نسخة الموقع الأصلية قبل تغييرات الإعلانات محفوظة في فرع Git باسم version-001.
