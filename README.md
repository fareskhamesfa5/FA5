# FA5 — فارس الجيل الخامس

موقع تعريفي عربي باتجاه RTL، بتصميم متجاوب ومظهر داكن/فاتح.

## هيكل الملفات

```
FA5/
├── index.html
├── README.md
├── assets/
│   ├── fA5-logo.png
│   └── fares-profile.jpg
├── css/
│   └── styles.css
└── js/
    └── main.js
```

## المميزات
- تصميم جديد بطابع إبداعي وهوية لونية مستقلة.
- دعم الموبايل والتابلت والكمبيوتر.
- مظهر داكن وفاتح مع حفظ الاختيار محلياً.
- تصفية مجالات الأعمال حسب النوع.
- أسئلة شائعة تفاعلية.
- قائمة هاتف متجاوبة وروابط تنقل داخلية.
- نموذج تواصل يجهز رسالة عبر تطبيق البريد الافتراضي؛ لا يخزن بيانات الزوار ولا يرسلها إلى خادم.
- مراعاة إعداد تقليل الحركة في الجهاز.

## التشغيل
افتح `index.html` أو انشر المستودع باستخدام GitHub Pages من الفرع `main` والمجلد `/(root)`.

الصور الموجودة في معرض الأعمال تصورات توضيحية مصممة داخل CSS وليست ادعاءً بمشروعات أو عملاء منفذين.
